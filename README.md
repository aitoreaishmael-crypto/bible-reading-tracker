# Bible Reading Tracker

A simple web app for reading through the whole Bible, one chapter at a time.

## Features
- Select a random chapter you haven't read yet
- Mark chapters as read, with the date
- Counts of chapters read and chapters yet to read (out of 1,189)
- Filter by Whole Bible, Old Testament or New Testament
- Undo a single chapter, or clear all progress
- Progress is saved in your browser

## Use it
Open the live site, or download index.html and open it in any browser.
